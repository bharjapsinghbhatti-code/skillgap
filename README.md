# SkillGap

### AI-Powered Career Skill Gap Analysis & Learning Roadmap

SkillGap is a career development tool that helps users understand the skills they need to move toward a target role.

Instead of simply showing a list of required skills, SkillGap compares a user's current skill level with role-specific requirements and combines this with market demand and career-growth signals to prioritize what they should learn next.

## What SkillGap Does

- Select a target career role
- Enter current skill levels
- Compare current skills against target requirements
- Identify the biggest skill gaps
- Prioritize skills using market demand and career growth
- Understand role readiness
- Identify strengths and weaknesses
- Get personalized learning actions
- Follow a structured 90-day learning roadmap

## Supported Career Roles

- Data Analyst
- Business Analyst
- BI Analyst
- Data Scientist
- Marketing Analyst
- Financial Analyst

Recommendations are role-specific, so the same skill can receive a different priority depending on the career path selected.
